# Soft Storybook edition

This is an independent main-map version. Existing play/ and cartoon/ files are preserved.

Run python3 storybook-lab/build.py, then node build-preview.cjs. The authored Blender scene and export script are saved in outputs/style-studies beside this checkout. Assets were reviewed as the brighter April Japan-and-neighbors main-map study.

The new map retains monthly country ratings, country/city selection, zoom, pan, optional orbit, top view, reduced-motion support, and the Australia gradient trial. Japan cherry trees grow in March and April. The earlier generic landmarks, animal proxies, beach umbrellas, and permanent sight labels are not included in this edition. All country guides remain linked from the existing play edition.
