# SEO learning log

## 2026-09-26: starting rules, not measured growth results

- Useful AI-assisted content is permitted; scaled content without user value risks Google spam enforcement. Daily publishing itself is not a ranking signal.
- Shared templates are fine. Distinct pages need distinct traveller decisions and sourced local substance. Consolidate overlapping intent rather than paraphrasing duplicates.
- Search Console access has not been verified. Establish indexing and search baselines before claiming outcomes.
- Analytics changed from opt-in persistent IDs to default memory-only IDs on 2026-09-26. Do not interpret the resulting increase in measured activity as organic growth.
- First hypothesis: clearer destination-specific titles and internal links may improve discovery of existing useful guides. Select a page only after inspecting evidence; no experiment has yet been launched.

For each experiment record: question, evidence/source links, affected URLs, change date, review date, result (supported/rejected/inconclusive), and next action. Private metrics belong outside this public repository.
