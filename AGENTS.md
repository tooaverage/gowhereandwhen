# GoWhereAndWhen working rules

Read `docs/COPY-RULES.md` for copy and corrections, `DESIGN.md` for layout, and `docs/CONTENT-FACTORY.md` for content and publication work.

When the user corrects earlier work, apply the installed `correction-ratchet` skill if available. Fix the issue, merge the scoped lesson into its existing rule file, and verify the real failure. Record one-off or tentative decisions as such. Do not expand a France-only correction into a worldwide rollout.

For city-map changes, run the read-only rendered check in `scripts/check-map-label-layout.js` across trip lengths and desktop/mobile views. Labels go right by default; exceptions need a documented collision or clipping reason.
